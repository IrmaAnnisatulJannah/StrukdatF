1. Bubble Sort¶

adalah pertukaran dengan waktu yang lama, pengecekan akan terus dilakukan jika terjadi pertukaran maka akan ditukar jika tidak pengecekan akan tetep terjadi, proses ini akan berulang sampe pertukaran akhir selesai. Bubble Sort adalah pengurutan yang paling sederhana.

Cara mengurutkan datanya adalah:

  1. data dibaca mulai dari yang paling kiri dari indeks 0 di suatu list data.
  2. lakukan perbandingan besar kecilnya data
  3. pindahkan satu posisi
  4. lakukan perbandingan seperti langkah ke-2 dan pindah satu posisi kembali seperti langkah ke-3. Lakukan terus menerus sampai indeks data terakhir.
  5. Setelah langkah ke-4 dilakukan, maka data yang berada di posisi paling kanan (indeks ke-N) adalah data terbesar .
  6. ulangi serta melakukan dan lakukan pengecekan

        for i in range(outIter+1,len(listData)):
            if listData[i]<listData[minIndex]:
                minIndex=i
        temp=listData[outIter]
        listData[outIter]=listData[minIndex]
        listData[minIndex]=temp

def QuickSortAwal(A):
    QuickSort(A, 0, len(A) - 1)

def QuickSort(A, start, end):
    if start < end:
        pIndex = Partition(A, start, end)
        QuickSort(A, start, pIndex - 1)
        QuickSort(A, pIndex + 1, end)

def Partition(A, start, end):
    pivot = A[end]
    pIndex = start

    for i in range(start, end):
        if A[i] <= pivot:
            A[i], A[pIndex] = A[pIndex], A[i]
            pIndex = pIndex + 1

    A[pIndex], A[end] = A[end], A[pIndex]
    return pIndex

3. Insert Sort¶

Pada algoritma insertion sort, diasumsikan bahwa sebagian data sudah dalam keadaan terurut (pada posisi sebelah kiri dari data list), sehingga data berikutnya akan dibandingkan dengan data yang sudah dalam keadaan terurut ini, dan disisipkan (insertion) pada bagian data yang sudah terurut tersebut. Dengan konsep seperti ini, posisi sebelah kiri dari list data (sebelum ada data baru yang akan disisipkan), selalu dalam keadaan terurut.

Berikut algoritma Insertion Sort :

  1. Asumsi bahwa data ke-1 sampai dengan (n/2) sudah dalam keadaan terurut
  2. Sisipkan data ke (n/2)+1 atau key ke dalam bagian data yang sudah dalam keadaan terurut, dengan cara:
  3. lakukan perbandingan data antara key dengan data pada indeks sebelumnya, jika key bernilai lebih kecil, maka lakukan pergeseran posisi data.
  4. lakukan terus perbandingan data key ini dengan data pada indeks sebelumnya, sampai data key tidak lebih kecil lagi atau atau sampai dengan data pada posisi pertama.

def insertion_sort(arr):
    # Start from the second element (index 1)
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        
        # Shift elements of arr[0..i-1] that are greater than key
        # to one position ahead of their current position
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        
        # Insert the key into its correct position
        arr[j + 1] = key
    return arr

# Example usage:

print(f"Original: {my_list}")
print(f"Sorted:   {insertion_sort(my_list)}")

4. Quick Sort¶

Algoritma sorting berikutnya adalah Quick Sort. Tahapan pengurutan algoritma ini sama halnya dengan algoritma Merge Sort, yaitu proses divide dan combine. Hanya saja Jika pada algoritma merge sort, proses divide, dilakukan dengan cara membagi data menjadi dua buah bagian, dan proses pengurutan terjadi pada proses merging/combine. Maka pada algoritma Quick Sort, terdapat perbedaan. Ada dua tahap algoritmanya yaitu divide dan combine

Berikut adalah penjelasan tentang 2 tahap tersebut:

1. Divide¶

Berbeda dengan algoritma merge sort yang membagi data menjadi dua bagian, tanpa syarat apapun, maka pada algoritma quick sort ini, pembagian data menjadi dua buah bagian, harus memenuhi ketentuan bahwa, data yang berada di bagian sebelah kiri (bagian data pertama), haruslah data-data yang memiliki nilai lebih kecil dari nilai pivot (tidak harus urut). Sedangkan, data-data yang berada disebelah kanan (bagian data kedua), adalah data-data yang memiliki nilai lebih besar dari nilai pivot, seperti yang terlihat pada Gambar 1.

Nilai pivot merupakan data yang terdapat pada indeks awal dari data yang akan dipartisi, misalkan 0. Baris pertama menunjukkan bawa data pivot disimpan dalam variabel . Untuk mencari data-data yang bernilai kurang dari pivot, maka dilakukan penelusuran, mulai dari data setelah indeks pivot, sampai dengan data terakhir yang akan dipartisi. Pada proses tersebut, pencarian direpresentasikan dengan variabel , lihat baris ketiga. Setelah didapatkan data yang memiliki nilai lebih kecil dari pivot, maka data tersebut ditukar dengan data yang terdapat pada data disebelah pivot, lihat baris kelima dan keenam. Posisi data terakhir yang memiliki nilai lebih kecil dari data pivot, disimpan dalam variabel i, sehingga pada baris ketujuh, dilakukan pertukaran dengan data tersebut dengan data pivot (lihat baris ketujuh)

2. Combine¶

Tahap kedua pada algoritma quicsort adalah tahapan combine. Pada tahapan ini, hanya memerintahkan partisi yang berulang kali. Data yang sudah dipartisi, akan terdiri dari dua bagian data, yaitu bagian pertama dan kedua. Bagian pertama dilakukan partisi lagi, menjadi dua buah bagian, begitu juga bagian kedua, begitu seterusnya, sampai tidak ada data lagi yang akan dipartisi. Sehingga hasil akhir adalah, data akan terurut. Pada contoh Gambar 2 tersebut, nilai pivot berada pada indeks ke-4. Nilai pivot di akhir proses partisi, menempati indeks yang sebenarnya, ketika data tersebut dalam keadaan terurut. Sehingga proses partisi akan dilakukan pada data-data sebelum nilai pivot, dan data setelah nilai pivot. Proses combine yang dilakukan dengan cara memerintahkan partisi berulang, seperti yang terlihat pada Gambar 3.

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]

    # Divide
    kiri = [x for x in arr if x < pivot]
    tengah = [x for x in arr if x == pivot]
    kanan = [x for x in arr if x > pivot]

    # Combine
    return quicksort(kiri) + tengah + quicksort(kanan)


# Contoh penggunaan
data = [8, 3, 1, 7, 0, 10, 2]

print("Data sebelum sorting:", data)

hasil = quicksort(data)

print("Data setelah sorting:", hasil)

Data setelah sorting: [0, 1, 2, 3, 7, 8, 10]

5. Merge Sort¶

Merge Sort merupakan algoritma pengurutan dengan konsep rekursif, yang terdiri dari dua tahapan utama, yaitu

1. Splitting atau proses divide¶

Proses Splitting atau Divide adalah proses yang membagi list data menjadi dua buah bagian. Proses splitting data list ini dilakukan secara terus menerus, sampai hanya tersisa satu elemen saja didalam list. Top-Down Process

2. Merging¶

Proses Merge ini menggabungkan data-data yang sudah terbagi pada Tahap pertama (divide/split). Proses merge ini juga melibatkan proses membandingkan data antara list yang akan digabung. Sehingga, setelah proses merge, data pada list akan terurut. Proses ini akan dilakukan terus menerus, sehingga tidak ada lagi list yang akan digabungkan. Tahapan merge ini adalah Bottom - up process

def merge_sort(arr):
    if len(arr) <= 1:
        return arr

    tengah = len(arr) // 2

    # Divide
    kiri = merge_sort(arr[:tengah])
    kanan = merge_sort(arr[tengah:])

    # Merging
    hasil = []
    i = j = 0

    while i < len(kiri) and j < len(kanan):
        if kiri[i] < kanan[j]:
            hasil.append(kiri[i])
            i += 1
        else:
            hasil.append(kanan[j])
            j += 1

    hasil.extend(kiri[i:])
    hasil.extend(kanan[j:])

    return hasil


# Contoh penggunaan
data = [8, 3, 1, 7, 0, 10, 2]

print("Data sebelum sorting:", data)

hasil = merge_sort(data)

print("Data setelah sorting:", hasil)

Data setelah sorting: [0, 1, 2, 3, 7, 8, 10]

6. Shell Sort¶

Shell Sort adalah algoritma sorting yang merupakan pengembangan dari Insertion Sort. Metode ini bekerja dengan membandingkan elemen yang berjauhan terlebih dahulu menggunakan nilai tertentu yang disebut gap.

def shell_sort(arr):
    n = len(arr)

    # Menentukan gap awal
    gap = n // 2

    # Perulangan selama gap lebih dari 0
    while gap > 0:

        # Perulangan untuk membandingkan elemen
        for i in range(gap, n):

            temp = arr[i]
            j = i

            # Sorting berdasarkan gap
            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap

            arr[j] = temp

        # Gap diperkecil
        gap //= 2

    return arr


# Contoh penggunaan
data = [12, 34, 54, 2, 3]

print("Data sebelum sorting:", data)

hasil = shell_sort(data)

print("Data setelah sorting:", hasil)

Data setelah sorting: [2, 3, 12, 34, 54]
