Definisi Stack¶

Stacks adalah satu struktur data dimana penambahan dan penghapusan data, hanya dapat dilakukan pada satu ujung yang sama, atau yang biasa dikenal dengan istilah top. Semakin data jauh berada dari posisi top, maka data tersebut diindikasikan berada di stack lebih lama dibandingkan dengan data yang berada dekat pada data di posisi top. Jika terdapat data baru yang ditambahkan di stack, maka data ini pulalah yang akan dihapus ketika terdapat proses penghapusan data. Konsep ini dikenal dengan nama LIFO-Last In First Out.

#cek kurung
def cek(s):
    stack = []
    for i in s:
        if i == '(':
            stack.append(i)
        elif i == ')':
            if not stack:
                return False
            stack.pop()
    return len(stack) == 0

Operasi pada Stacks¶

Terdapat operasi dasar pada Stacks,

  • stack (), inisialisasi stack yang kosong
  • push(data), penambahan data baru pada posisi top dari stack
  • pop(), penghapusan data yang terdapat di posisi top dari stack. R eturn value dari fungsi ini adalah data yang dihapus dari stack tersebut
  • peek(), informasi data yang terletak pada posisi top
  • isEmpty(), untuk memeriksa apakah stack dalam keadaan kosong
  • size(), informasi jumlah data yang terdapat pada stack

class Stack:
  def __init__(self):
    self.stack = []

  def push(self, element):
    self.stack.append(element)

  def pop(self):
    if self.isEmpty():
      return "Stack is empty"
    return self.stack.pop()

  def peek(self):
    if self.isEmpty():
      return "Stack is empty"
    return self.stack[-1]

  def isEmpty(self):
    return len(self.stack) == 0

  def size(self):
    return len(self.stack)


myStack = Stack()

myStack.push('B')


print("Stack: ", myStack.stack)
print("Pop: ", myStack.pop())
print("Stack after Pop: ", myStack.stack)
print("Peek: ", myStack.peek())
print("isEmpty: ", myStack.isEmpty())
print("Size: ", myStack.size())

Definisi Queue¶

Pengertian

Queue (antrian) adalah struktur data di mana: data masuk dari belakang (rear) data keluar dari depan (front) Menggunakan prinsip FIFO (First In First Out), yaitu yang masuk dulu keluar dulu.

Konsep Penting Front: elemen pertama (yang akan keluar)

Rear: elemen terakhir (tempat masuk data baru)

FIFO: urutan berdasarkan waktu masuk

Operasi pada Queue

  • enqueue(item) → menambah data ke belakang

  • dequeue() → menghapus data dari depan

  • isEmpty() → cek apakah kosong

  • size() → jumlah data

Contoh :

Queue awal: []

enqueue(10) → [10]

enqueue(20) → [10, 20]

enqueue(30) → [10, 20, 30]

dequeue() → 10 keluar

hasil: [20, 30]

class Queue:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def enqueue(self, item):
        self.items.insert(0, item)

    def dequeue(self):
        return self.items.pop()

    def size(self):
        return len(self.items)


# Contoh penggunaan
q = Queue()
q.enqueue(10)
q.enqueue(20)
q.enqueue(30)

print("Queue:", q.items)
print("Dequeue:", q.dequeue())
print("Queue sekarang:", q.items)

Queue: [30, 20, 10]
Dequeue: 10
Queue sekarang: [30, 20]

Definisi Deque (Double Ended Queue)¶

Pengertian Deque adalah struktur data yang mirip queue, tetapi bisa:

menambah data dari depan maupun belakang, menghapus data dari depan maupun belakang Jadi, deque lebih fleksibel dibanding queue.

Konsep Penting

  • Memiliki dua sisi: front dan rear

  • Tidak hanya FIFO, bisa berbagai pola tergantung penggunaan

Operasi pada Deque

  • addFront(item) → tambah ke depan

  • addRear(item) → tambah ke belakang

  • removeFront() → hapus dari depan

  • removeRear() → hapus dari belakang

  • isEmpty() → cek kosong

  • size() → jumlah data

Contoh

Deque awal: []

addFront(10) → [10]

addRear(20) → [20, 10]

addFront(30) → [20, 10, 30]

removeRear() → 20 keluar hasil: [10, 30]

Berikut Implementasi Codenya:

class Deque:
    def __init__(self):
        self.items = []

    def isEmpty(self):
        return self.items == []

    def addFront(self, item):
        self.items.append(item)

    def addRear(self, item):
        self.items.insert(0, item)

    def removeFront(self):
        return self.items.pop()

    def removeRear(self):
        return self.items.pop(0)

    def size(self):
        return len(self.items)


# Contoh penggunaan
d = Deque()
d.addFront(10)
d.addRear(20)
d.addFront(30)

print("Deque:", d.items)
print("Remove rear:", d.removeRear())
print("Deque sekarang:", d.items)

Deque: [20, 10, 30]
Remove rear: 20
Deque sekarang: [10, 30]

#cek palindrome
from collections import deque

def palindrome(kata):
    d = deque(kata)
    while len(d) > 1:
        if d.popleft() != d.pop():
            return False
    return True

def cek_palindrome_stack(kata):
    stack = []

    # push ke stack
    for huruf in kata:
        stack.append(huruf)

    # pop dari stack untuk membalik
    hasil = ""
    while stack:
        hasil += stack.pop()

    # cek
    if hasil == kata:
        return "Palindrome"
    else:
        return "Bukan Palindrome"


# contoh
print(cek_palindrome_stack("katak"))
print(cek_palindrome_stack("halo"))
